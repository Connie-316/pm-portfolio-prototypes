## 设计要点

- **多商品优惠分摊**：按商品金额占比分摊，含四舍五入与尾差吸收规则，保证分摊后金额合计等于券面优惠额
- **部分退款不退券**：退款场景下的券状态流转矩阵，覆盖 8 种组合
- **尾差吸收项**：解决分摊计算中「分」级尾差导致的金额不平
- **规则与原型强一致**：PRD 每一条状态规则都对应到具体原型页面
- **异常与边界态成页**：抢券并发失败、已达限领幂等拒绝、网络超时重试、积分与券互斥、限时折扣与券互斥，均有独立原型页
- **金额自洽**：原型内商品金额、优惠分摊、积分抵扣、实付金额**逐页可验算**
  - 确认订单页：81.40×5 + 1580.00 = 1987.00 → 券 −50 → 积分 −10 → 实付 1927.00
  - 退款退券 4 态统一采用 PRD §4.6 基准订单（刀入子 ¥600 + 精密导柱组件 ¥400 = ¥1000，满 500 减 50）：
    整单退款退实付 **¥950**（券按未过期 / 已过期 / 已核销三种状态分别退回 / 作废 / 不退回）；
    部分退款按原价占比分摊（¥600 → 分摊 ¥30 → 退 **¥570**，剩余商品应付 ¥380，两侧合计数与 ¥950 一致）
