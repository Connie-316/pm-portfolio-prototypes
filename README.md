## 设计要点

- **多商品优惠分摊**：按商品金额占比分摊，含四舍五入与尾差吸收规则，保证分摊后金额合计等于券面优惠额
- **部分退款不退券**：退款场景下的券状态流转矩阵，覆盖 8 种组合
- **尾差吸收项**：解决分摊计算中「分」级尾差导致的金额不平
- **规则与原型强一致**：PRD 每一条状态规则都对应到具体原型页面
